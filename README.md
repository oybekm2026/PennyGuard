# PennyGuard

A small personal expense tracker built with HTML, CSS, and vanilla JavaScript.

## Features
- Add an expense with a fixed category, amount, and date
- See total spending and current-month spending by category
- Delete an expense
- Keep entries in this browser using `localStorage`
- Responsive layout for desktop and mobile screens

## Run locally
Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Data and privacy
Expense entries are stored only in the current browser's local storage. They are not uploaded to a server or synced between devices. Browser storage is not encrypted and may be cleared by the browser.
